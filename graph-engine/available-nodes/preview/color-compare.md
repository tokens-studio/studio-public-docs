# Color Compare

### What It Does
The Color Compare node displays two colors side-by-side for visual comparison. It helps you evaluate color combinations and contrast relationships.

### Inputs
| Name | Description | Type | Required |
|------|-------------|------|----------|
| Color A | The first color to compare | Color | No |
| Color B | The second color to compare | Color | No |

### Outputs
| Name | Description | Type |
|------|-------------|------|
| *No outputs* | This node is for preview purposes only | - |

### How to Use It
1. Drag the Color Compare node into your graph.
2. Connect a color value to the "Color A" input or use the default white (#ffffff).
3. Connect a color value to the "Color B" input or use the default black (#000000).
4. The node will display both colors side-by-side in the editor for visual comparison.

### Tips
- Use this node to visually check contrast between two colors.
- Preview both colors in context to evaluate their relationship.
