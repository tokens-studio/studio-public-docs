# Inviting members

{% stepper %}
{% step %}
### Under your project name, you'll find a small menu.

<figure><img src="../../.gitbook/assets/InviteMembers01.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Click on 'Invite members.

This will open a page.

<figure><img src="../../.gitbook/assets/InviteMembers02.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Here you see all the current members.&#x20;

Via the button 'Invite users' you will be able to invite new members

<figure><img src="../../.gitbook/assets/InviteMembers03.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Just drop the mail address and hit the button!

An invite will be sent to the email address.&#x20;

<figure><img src="../../.gitbook/assets/InviteMembers04a.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}
