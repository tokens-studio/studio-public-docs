# Getting Started



### Sign up

If you're already signed up you can skip ahead.

If you haven't signed up yet, you can sign up here: [https://app.tokens.studio/auth/register](https://app.tokens.studio/auth/register)

Sign up with your email or Google account.



### Activating your Account

After confirming your email you will land on the Waitlist page. You should have received an activation code in your onboarding email.

Please use this inside the "Redeem" field to get access to Studio.
